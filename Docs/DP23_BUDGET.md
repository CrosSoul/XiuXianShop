# DP-23 最终净额预算与自愿少收

正式依据：Confluence G-02/G-08（2293763 v2）、G-05（1310722 v3）、AC-36—AC-39（950291 v3）。本轮不修改正式文档。开始时 main/a339f71，工作区干净；保留 DP18 和日历成果。

## 实现与账目

- 所有买卖明细先求净额 N。仅正净额消耗顾客预算；+21−3=+18、预算18可直接成交。零或负净额不消耗、不补充顾客预算。
- N 超过预算 B 时，首次确认只显示“继续交易将少收 N−B 灵石”，实际净收 B。取消无变化；同意后重新校验并整笔成交。
- 让价作为整笔金额调整：实际收入小计=卖出报价小计−少收额，支出小计仍为买入报价合计，两者之差等于实际资金变化。成交消息同时记录报价净额、实际净额和少收额。不修改基础值或标签，不给多件商品擅自分摊折扣；玩家购入实例仍记录实际买入报价。
- 提醒绑定顾客、清单实例及归属位置、预算、玩家资金、行情版本与逐项报价。条件变化后旧提醒失效，确认再次检查实际落位；失败或重复点击不部分成交。
- 本轮改动 ShopTradeQuote、ShopSession、ShopNegotiationView 及对应 Edit/Play 测试，无场景、Prefab、Package、存档格式或经济系统扩展。
