# DP-27 地点选择与往返

依据 [DP-27](https://zzrzzrzzr11.atlassian.net/browse/DP-27)、[G-11 v8](https://zzrzzrzzr11.atlassian.net/wiki/spaces/D/pages/2850836)、[G-03](https://zzrzzrzzr11.atlassian.net/wiki/spaces/D/pages/1736718) 与 [G-04 AC-41/42](https://zzrzzrzzr11.atlassian.net/wiki/spaces/D/pages/950291)。只读取任务依据及相关实现，没有全量阅读GDD。

## 当前行为

- 从“出门携带”选择已有背包或不带背包，整理左右手和背包，再点“出发 · 选择地点”。取消选择或结束准备不算外出；点击出发开始占用本回合唯一一次外出。
- 正常开局显示百事堂、听风茶肆。地点配置包含稳定ID、名称和初始解锁开关；运行时解锁与访问标记分开。未解锁不显示，访问过或体力不足显示灰色及原因。
- 首个地点60体力、同次额外不同地点30，位于ShopCatalog中可调。进入时扣一次；地点展示、整理随身物与离开不再扣体力。100→40→10。
- 地点选择中，仍有当前可去地点才弹回店确认；取消继续外出，没有可去地点直接回店。本回合不能再次出发，下一回合重置。
- 同一实例的背包、左右手、内部内容跨地点保留；外出时不能访问店内仓库、展示柜、柜台或丹炉。
- 回店不要求仓库有空位，也不强制卸货。保留携带面板供整理，点击“结束携带 / 返回”沿用已有全量卸货检查；空间不足不丢物，可先整理再卸货。满仓最终自动处理规则仍未设计。
- 准备阶段存档保留本回合外出标记和解锁地点，避免回店存读档重置次数。携带/外出过程仍禁止存读档；已有配置签名校验保留，旧签名文件拒绝且不后台改写，无存档迁移。

## 手动验收

1. 正常打开ShopPrototype场景并Play，仓库已有测试腰包与储物匣，无需Validation菜单。
2. 在腰包中预装物品，点击“出门携带”，选择该腰包并确认；将一件物品拖入手中，点击“出发”。
3. 点击“回店铺”，出现确认，点击“继续外出”，保持100体力与物品不变。
4. 进入百事堂，体力40；将随身物在手和腰包之间搬运，离开后百事堂灰色，体力不变。
5. 进入听风茶肆，体力10；离开并回店，不弹确认。背包和手中物品保持原实例。
6. 整理并结束携带，再打开携带面板，没有“出发”入口。正常营业、闭店、推进下个月后恢复一次外出资格。
