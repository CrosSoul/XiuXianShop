# DP-28 地点物品状态与往返物流

依据[DP-28](https://zzrzzrzzr11.atlassian.net/browse/DP-28)、[G-11 v8](https://zzrzzrzzr11.atlassian.net/wiki/spaces/D/pages/2850836)的地点格子、实例连续性与离开清理，以及[G-01储存规则](https://zzrzzrzzr11.atlassian.net/wiki/spaces/D/pages/1736718)。未全量阅读GDD。

## 已实现

- 正常地点界面上方增加物品格子，下方保留左右手与所选背包。默认6×4是可调原型容量，不是正式职业设备容量。
- 使用现有物品实例和摆放逻辑，在当前地点格子、左右手、所带背包之间拖放。旋转、翻转、越界和重叠沿用现有规则；失败不移动，切换界面不复制，不自动将地点物品传回仓库。
- 普通地点仍有未带走物品时，“离开”弹出件数和清理后果；取消留在原地点且不改变物品，确认才清理该地点遗留物。全部取走直接离开，不影响左右手、背包及内部内容。
- 每个地点有独立物品归属。长期测试地点启用preserveItemsBetweenVisits，离开不清理；其他普通地点清理不会删除它的物品，下回合再次进入仍可取回。
- 长期地点物品随已有准备阶段存档保存，保留地点ID及实例字段；没有扩展成外出过程存档，没有创建种植、养殖字段。旧配置签名不匹配仍拒绝并保留原文件。
- 地点内部搬运与离开不追加体力，沿用DP-27进入时一次结算。

## 正常场景试玩

1. Play后将普通物品装入测试腰包，点击“出门携带”，选择腰包并出发，进入百事堂。
2. 将背包物品拖到上方地点格子，再拖回左右手或背包，检查同一物品可反复搬运。
3. 留一件在地点，点击“离开”→“留下整理”，应继续留在地点且物品不变。
4. 再点“离开”→“确认离开并清理”，地点遗留物消失，随身物保留；进入另一地点不出现刚才的遗留物。
5. 回店并结束携带，已收起的物品进入仓库或仍在原背包内。

普通开局不生成随机战利品或虚构奖励；地点初始为空，可用预装物品直接验证搬运和清理。

## 隔离验证入口

Play时菜单 `XiuXianShop/Validation/Start DP28 Location Items Example (resets Play session)` 重置为临时测试会话，提供临时地点、长期地点和测试腰包，不修改正式配置资产。进入地点后，`DP28 Add Test Pill At Current Location` 每次生成一件测试丹药到地点区，空间不足不生成；只有该隔离会话允许此菜单生效。

长期验证：在长期测试地点留下物品并离开，去临时地点留下另一件并确认清理；回店、正常营业闭店、推进下个月，体力足够后再次前往长期地点，原物品仍在。可在回店结束携带后的准备阶段保存/读取，测试文件位于Temp/DP28VerificationSave.json，不覆盖正常存档。

## 边界

- 百事堂委托、茶肆消息、炼丹配方、灵田与兽园职业状态均未实现。长期测试只验证现有物品状态不会被普通清理删除，不把测试物品等同于种植养殖数据。
- 仍沿用储存物品只能放仓库/明确携带位、不能嵌套的规则；未开放储存容器的地面丢弃、交易或内容销毁。普通物品及允许的实体设备可使用地点区，设备不能因此收入普通背包。
- 回店满仓仍按DP-27保留携带、先整理再卸货，不引入自动销毁或溢出仓库。
- 主要文件：ShopSession.LocationItems.cs、ShopSession.Travel.cs、ShopSession.cs、ShopSave.cs、ShopPrototype.Travel.cs、ShopPrototype.cs、PrototypeBuilder.cs和ShopCatalog.asset。资产经Unity API保存，场景、Package与Project Settings不改。
