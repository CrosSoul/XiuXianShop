# DP-31 便携储存与左右手携带

依据 [DP-31](https://zzrzzrzzr11.atlassian.net/browse/DP-31) 与 [G-11 v1](https://zzrzzrzzr11.atlassian.net/wiki/spaces/D/pages/2850836)。本轮只实现携带基础，不实施DP-27地点/行程或DP-28物流。

## 已实现

- 顶部“出门携带”打开选择界面，始终提供“不带背包出门”；按实例ID列出实际拥有的便携储存。确认移动原实例，取消/Esc不改变库存和内容。中途不能换包。
- 携带面板有左手、所选便携储存内部格子、右手。每只手一个实例，手持不按几何形状判断；显示按槽位缩放，不修改物品本身形状。
- 不带背包没有额外格子。已有预装内容仍归同一容器；支持手/仓库/便携内部搬运，沿用有限格子、碰撞、旋转与翻转。禁止嵌套，生产设备不能收入便携内部。
- 收起/重开不结束携带，不复制内容。结束携带仅在所有外部携带物均有合法仓库位置时一起返回；空间不足保留全部状态并提示先整理。这是当前限制，不是满仓返店的最终设计。
- 手持一个装有内容的储存物品也保留内部归属，不因离开根层而使内容变成非法状态；中央可操作内部仍只属于选中的便携储存。
- 沿用现有Session和物品ID，不增加独立背包副本或装备系统。历史购买价值、所有权和内容归属不因携带重置。

## 直接试玩

正常Play开局保留原7件商品、上一轮添加的“储物匣（测试）”，另有“腰包（携带测试）”：外部2×3、内部3×3，复用已有测试配置，不参与交易，不设正式价格/获取方式。无需Validation菜单。

1. 点击仓库腰包，放入一件草药，关闭窗口。
2. 点击顶部“出门携带”，先选腰包后取消，原物品与内容不变。
3. 再选择腰包并确认，中央显示该实例及预装草药；将草药拖入左手，木剑拖入右手，再把草药放回腰包。
4. 收起后再点“出门携带”，检查没有复制或清空；点击“结束携带 / 返回”恢复仓库。
5. 再选“不带背包出门”：仍有左右手，中间不出现储存格子。

## 保存与范围

携带过程中明确拒绝保存/读取，先返回再使用已有v3营业准备存档；未扩张成外出存档，也未改变v3格式。正常返回后的背包内容可保存恢复，现有签名检查仍适用。测试腰包加入目录后，旧目录快照不自动迁移；旧存档原件不被后台重写。

不包含地点选择、出行次数/成本、场景物流、设备运行、负重/体力或完整装备。未知尺寸、正式价格、获取方式与最终满仓策略仍待设计。携带面板是基础操作界面，不代表已到达某个地点；本版保留仓库用于备货与整理。
