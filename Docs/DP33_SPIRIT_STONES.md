依据 [DP-33](https://zzrzzrzzr11.atlassian.net/browse/DP-33) 和 [G-07 / G-09](https://zzrzzrzzr11.atlassian.net/wiki/spaces/D/pages/2064394)。仅实现物品与资源基础；未实现兑换、实物付款、供能或修炼。

满额灵气分别为1、100、10000等价量。隔离配置暂用每等价100个整数单位（精度0.01）、中品壳价7、上品壳价23；这些仅用于验证，不是正式平衡。下品耗尽粉碎、不留壳；中上品保留同一空壳且可补充。

## 实现

- ItemCategory追加三个玩家可见品级，资源能力单独配置，不属于格子储存类别。正常商品资源配置为空。
- GridItem保存独立SpiritUnits，基础价值使用容器价格＋剩余等价灵气，decimal计算后沿用现有交易整数舍入规则。消耗/补充不改物品ID、归属、历史买入价或钱包。
- 操作检查自有实例、正数量、剩余量与容量；失败不改变状态。灵气变化刷新报价和详情，开业后的展示快照仍不重算。
- 同一物品沿用原仓库、展示、柜台、携带与内部格子移动，不创建内容物副本。
- 现有v3准备存档增加资源存在标志与剩余量，恢复检查非法量和缺失资源数据。原配置签名检查仍保留：旧签名不匹配时拒绝读取且不重写旧文件；不提供迁移。隔离样例存档在Temp独立路径，不覆盖正常存档。

## 人工验收入口

1. 打开ShopPrototype并Play，在XiuXianShop → Validation执行 **Start DP33 Spirit Stones (resets Play session)**，会重置当前运行会话。
2. 仓库出现下品一件、中品两件、上品一件和测试便携储存。中品竖向2格，上品4格；点击查看品级、灵气与当前价值。
3. 执行 **DP33 Consume Half of Each Stone**：下品0.5，中品50，上品5000；再执行一次，下品粉碎，中上品变为空壳。基于测试壳价，中品价值7，上品23。
4. 执行 **DP33 Refill Reusable Stones**：中上品恢复满额，下品不重生；物品数量与原实例保持。
5. 测试拖入展示、便携内部和双手，收起重开后资源不重置。先结束携带，再从日历保存/读取隔离准备存档。

退出Play后隔离配置销毁；正常开局仍是原商品，不含草稿灵石。实际供能、收费充能、兑换及实体支付留给后续任务。
