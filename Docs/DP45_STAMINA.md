# DP-45 营业外体力基础

依据 [DP-45](https://zzrzzrzzr11.atlassian.net/browse/DP-45)、G-04 v9 AC-40/42/46、G-01/G-03 v5与G-11 v7。按需读取这些正式依据，未扩展长期玩法。

## 当前实现

- ShopCatalog配置体力上限100、每月恢复30；开局采用满体力且首月无恢复奖励的原型起点。新游戏起点尚非独立正式平衡规则。
- 只有成功推进到下个月时恢复一次；恢复前体力＋恢复量严格大于上限时，本月客流在原5名基础上增加1名。恰好满额无奖励，无论溢出多少只加1名。
- 额外顾客沿用现有每位随机买卖方向、展示类别、预算档位及来货生成，不创建新客群分布。重复预览、开界面、重复开始营业或错误推进不会重复恢复/追加；下一月奖励重新计算，不累计。
- CanSpendStamina检查活动成本；TrySpendStamina只在营业外阶段扣除配置成本，允许恰好扣至0，不足或负成本失败且不改变体力。业务调用方必须先验证材料等其他前置，再提交一次体力支付；地点以后仅进入时调用，不能在内部重复扣费。
- 开始/结束营业均不扣体力，不以体力不足禁用开店。主界面显示体力、每月恢复与溢出奖励，客流文案跟随5/6变化。
- 现有v3准备阶段存档保存当前体力与本月奖励，读取只还原状态，不恢复或重抽奖励。缺失/越界体力拒绝读取；旧配置签名不匹配仍拒绝且保留原文件，不迁移旧存档。

## 人工验证

1. 打开ShopPrototype并Play，左上方可见体力100/100，首月5位。直接营业、闭店、推进下月：体力100，奖励+1，本月6位。
2. 在准备或闭店阶段通过XiuXianShop → Validation → **DP45 Spend Configured Test Stamina (Play session)** 模拟消费。成本读取ShopCatalog.staminaTestActivityCost，默认20，仅验证用途，不能视为任何正式活动价格。
3. 新开局连续执行5次，体力降至0；再执行一次提示不足，仍为0。正常开店、闭店、推进后体力30，无奖励。
4. 可在退出Play后于ShopCatalog Inspector调整测试成本为30或10；新开局消费一次，分别留下70或90，推进后均为100，但仅90的路径奖励+1。测试完成恢复测试成本20。
5. 准备阶段先保存，再多次读取同一存档；体力与奖励不变。反复开关日历，随后开店验证总共6名而非重复追加。
