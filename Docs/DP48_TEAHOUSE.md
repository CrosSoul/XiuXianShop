## 已实现行为

进入听风茶肆时沿用外出入口扣费，并抽取一次结果；重复打开消息不扣费、不重抽。普通效果只影响下一回合营业，当回合和再下一回合不生效；下一次访问产生的待生效消息与本回合加成分别保留。

| 效果 | 默认权重 | 默认作用 |
| --- | --- | --- |
| 求购风向 | 28 | 选定类别买家权重 ×2 |
| 供货风向 | 28 | 选定类别供货权重 ×2 |
| 商旅到访 | 18 | 携货求购概率 +25 个百分点，上限 85% |
| 宣传店铺 | 10 | 下一回合顾客 +1，可与体力溢出奖励叠加 |
| 阔客风声 | 10 | 随机一名顾客预算提高 1 档，不超过顶档 |
| 市场秘闻 | 6 | 提前获知当前回合后 2–12 回合内开始的一项行情 |

以上权重、倍率、概率、人数、档位与秘闻范围均在 `Assets/Data/ShopCatalog.asset` 的 Tea House 配置中调整，资产通过 Unity API 保存。

风向使用现有展示柜筛选后的候选池：买家已有固定类别时不会重新加入其他类别；卖家仍遵守广告牌筛选。随机买家类别原始等权，供货沿用商品候选等权，再对目标类别乘倍率并归一化。因此只有一个候选类别时，倍率不会改变结果。

秘闻优先选择窗口内已有的未来行情；没有时从现有行情池安排合法事件，同类型冷却和后续普通生成共用校验。无合法安排则改抽其他效果，不强行插入。已知行情在日历以金色显示完整起止时间及持续条，实际价格仍只在事件生效期间变化。普通未知未来行情继续隐藏。现有测试用行情频率、持续和冷却参数未改成正式平衡数据。

消息窗口可从地点内或店铺“坊市消息”打开。准备阶段存档保留消息、加成与已知行情；没有开放外出中存档。复用 Unity 序列化的存在标记，避免空消息被还原为默认对象。

## 手动验收入口

1. 正常 Play → 出门携带 → 出发 → 听风茶肆。查看消息，关闭后再开；结果、体力应保持不变。
2. 离开并回店，整理卸货。店铺“坊市消息”应显示同一消息；本月尚无新加成。
3. 结束营业并推进一个月，再营业，核对消息所述加成；再推进一个月应过期。不同效果按默认权重随机出现，无需修改 Editor 配置即可正常游玩。
4. 抽到市场秘闻时打开日历，未来事件应显示类型和完整持续条，说明为“未开始”；普通未获知未来行情仍隐藏，到期后价格才生效。

无需手动挂组件或配置资产。若要确定性复核全部效果，可运行现有 DP48 自动测试；无需为了验收修改正式概率。
