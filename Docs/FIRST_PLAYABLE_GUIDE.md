# 第一阶段原型：试玩指南

## 入口

打开 `Assets/Scenes/ShopPrototype.unity`，点击 Unity Play。也可以使用菜单 `XiuXianShop > Open Playable Prototype`。场景和 ShopCatalog 引用已经配置，不需要手动创建对象。

建议最大化 Game 窗口，方便阅读中文和格子。界面会等比缩放以显示完整布局。退出 Play 再进入会重开第 1 天；可以在日历的营业准备阶段保存/读取磁盘存档，睡觉跨日保留当前资源。

点击顶部“日历”查看两周日期和收租提示。行情到开始当天才显示完整持续条，点击条查看效果；同类行情结束后留出两个完整空白日。已公开的跨周持续条正常显示，未来尚未开始的行情隐藏。详见 [日历交接](DP17_CALENDAR.md)。

本轮 v3 新增动态报价、购买历史、右侧交易明细和日结算。若希望确定性体验买卖双方及 20→23→17、收购16案例，按 [v3 交接的约5分钟验证日](TRADING_SLICE_V3.md#开发者可重复验证约-5-分钟) 使用 Play 中的 Validation 菜单；正常开局仍使用原始物品和随机客流。

## 操作

| 操作 | 方法 |
| --- | --- |
| 移动 | 鼠标左键拖动物品的有色占格，放入目标容器 |
| 查看物品 | 点击物品，在右下详情查看名称、类别、归属、基础/预估价值、价格标签和购买历史（若有） |
| 旋转 | 拖动时按 R，或选中后点击“旋转” |
| 水平翻转 | 拖动时按 F，或选中后点击“水平翻转” |
| 取消拖动 | Esc；放在格子外或非法位置也会保留原位 |
| 放置预览 | 绿色可以放；红色表示碰撞、越界或容器规则不允许 |
| 买入 | 顾客商品在柜台，点击“确认收购”；校验资金和空间后统一扣款、入库并记录实际购买价值 |
| 卖出 | 拖入任意自有物品；整批物品符合顾客类别且总价不超过剩余资金时，确认出售 |
| 分次出售 | 成交后买家继续停留，可以再摆放商品；“摆入一件同类商品”只提供快捷摆放 |
| 跳过顾客 | 点击“送别并接待下一位”；无人时为“呼叫下一位顾客”，未售物品留在柜台 |
| 炼丹 | 背包中有 1 凝气草和 1 灵露，点击“炼制回气丹” |
| 跨日 | 结束营业后查看右侧收支结算，点击睡觉进入下一天 |

背包 10×7，展示柜 6×4，柜台 5×4。三个容器都使用同一套实际占格规则。物品上的“己”表示玩家所有，“客”和蓝色边框表示顾客所有。顾客商品不能未经结算拖进背包。

## 第一次两天试玩（约 5–10 分钟）

初始有 120 灵石、7 件物品和已拥有的丹炉。格子坐标按左上角第 1 列、第 1 行开始计数。

1. 将紫色收购牌放在展示柜左上角；将金色回气丹放在展示柜第 3 列、第 1 行。它们不会重叠。
2. 观察营业前预览：每日 5 位，仅求购 40% / 携货求购 60%，买家偏好丹药，资金范围 18–22。
3. 点击“开始营业”。五位顾客均有求购类别和预算，分别随机决定是否携货；实际比例会变化。
4. 来货在独立顾客柜台显示，拖入谈判柜台自动打开弹窗，或从入口请求全部买入；每位顾客都可求购，拖一盒回气丹到柜台。正常基础18加零售15%，逐件取整报价21；预算至少21才可售，不足时可跳过。成交后买家仍停留，可以继续交易或下一位。
5. 接待或跳过五位后应没有第六位。拒绝和直接跳过不扣钱；多次向同一买家成交也不会占用额外顾客名额。
6. 结束营业。用背包中的凝气草与灵露炼丹；原料数量决定可炼制次数，随机供货不保证每天恰好两组原料。
7. 睡觉进入第 2 天，库存、资金和丹炉保留。将新丹药放入展示柜；两盒基础展示价值36时，买家资金范围变为54–66。展示值不受零售标签影响。
8. 第二天重新生成五位客人，按同样方式经营，然后闭店、睡觉进入第 3 天。实际现金取决于随机来客和你的成交选择，不再使用固定的 178 灵石作为验收值。

以上完整路径已经通过真实 Input System 模拟鼠标点击、拖放的 Play Mode 自动测试；仍需开发者亲自试玩来判断操作手感和理解成本。

## 单独体验形状空间

在新一局营业前进行，完成后可重新进入 Play 重置，或把物品移回背包：

1. 将单格灵露放入展示柜左上角。
2. 从凝气草左上方有色格抓起，将其形状的左上角对准同一位置；此时与灵露冲突，预览为红色。
3. 保持拖动，按 F。L 形缺口翻到左上，避开灵露，预览变为绿色，松开可以嵌放。
4. 将四格木剑从顶部格抓起，拖到展示柜最下行的左端。竖放越界；按 R 横放后可以放入。
5. 再尝试把横剑拖到最下行右端越界位置，应回到原位。观察物品总数不变。

## 经营规则

- 每日固定生成五位顾客，空展示柜也能开门。每一位都有求购类别和预算，单独随机决定是否携货；展示只改变概率，不增加人数或保证每天有来货。
- 默认携货概率：空展示柜 40%；仅可售商品 20%；仅有效广告牌 80%；商品与广告牌都有 60%。其余概率为仅求购顾客。广告牌、商品概率加成按有无计算，重复摆放不叠加。
- 收购牌不可出售，当前广告类别为材料；生成的卖家从凝气草、灵露、朱砂中随机携带两件。没有有效广告牌时，卖家从配置中的可供货商品随机选择；不会根据玩家库存限制供货。
- 买家仅受展示中**总基础价值最高的单一商品类别**影响；按每份物品基础值累加，同类不同商品也合并。价值并列时按类别枚举顺序确定。无可售展示时从商品配置的可售类别中随机求购，不要求仓库有货。
- 只有生效类别的总基础价值用于预算档位，其他类别不叠加预算。当前默认档位如下；每位买家在该档整数范围内独立随机抽取资金，同档内展示值变化不提高资金范围。

| 生效展示基础总价值 | 基准资金 | 实际携带资金（±10%） |
| --- | --- | --- |
| 0–29 | 20 | 18–22 |
| 30–99 | 60 | 54–66 |
| 100–299 | 150 | 135–165 |
| 300 及以上 | 400 | 360–440 |

- 例如展示价值 20 与 22 都使用 18–22 档；两盒回气丹价值 36 进入 54–66 档。上下限包含，下一档从其门槛值开始。
- 物品类别：回气丹为丹药；凝气草、灵露、朱砂为材料；木剑为装备；玉匣为容器；收购牌为不可出售的业务招牌。
- 客源只在“开始营业”时检查一次。此后移走或添加展示物品、招牌都不改变当天已确定的客人；新展示内容到下一天开门才生效。
- 自有物品在营业前、营业中、闭店后都可在仓库、展示柜和柜台之间自由搬动，仍须满足格子边界和碰撞规则。柜台可放任意类别、任意一份实物。
- 确认出售检查柜台上的全部自有物品：不能为空、必须可出售、全部符合顾客类别，总价不超过剩余资金。任何一项失败都会锁定按钮并显示原因，不会部分出售或扣款。
- 成交后扣除顾客资金、增加玩家灵石，移除整批售出物品；买家继续停留，可重复成交。随时可以切换下一位，即使尚未成交。拒绝、换客、闭店不会移动玩家未售物品。
- 炼丹只消耗背包里的玩家原料。展示柜或柜台里的原料不计入。
- 收购钱不足或背包放不下时不扣款。可整理背包，或在柜台旋转顾客物品后再试。
- 回气丹占 2×2；炼丹会考虑原料释放出的空间。如果仍放不下成品，原料不消耗。
- 基础价值与报价分开：正常草基础3、灵露2、丹药18；无额外标签的收购报价等于基础值，出售默认+15%，逐件四舍五入。仓库预估为基础值，进入柜台才显示交易报价；实际买入价格记录为历史。价格与临时边界见 v3 交接，不再使用旧固定买卖价计算毛利。
- 顾客来货先进入独立顾客柜台，手动拖入谈判柜台后才纳入所选清单；也可直接跳过。闭店右侧显示本日收入、支出、余额变化；租金在随后睡觉时支付。
- 每 7 天夜间收房租，首期 20，下期向上取整上涨约 5%。不够支付的部分记为待付房租，后续夜间用现有灵石偿还，不会出现负灵石或强制结束。没有 72 天倒计时。

## 本次客流与档位的手动验收

以下路径使用当前默认配置，随机顾客不保证固定出现顺序。重新进入 Play 可重开一局，或闭店睡觉开启新一天。

1. **空展示**：不摆展示物品，直接开门。应有五位客人，按五次下一位全部跳过后没有第六位。买家的求购类别可以是仓库没有的类别。
2. **最高类别**：营业前摆一盒丹药（18）、玉匣（14）、木剑（10），预览只显示丹药；其他类别合计 24 不会取代丹药或加进预算。
3. **档位跨越**：从新一局使用初始原料炼一盒丹药，展示两盒，价值由 18 变成 36，预览资金由 18–22 切为 54–66；开门后的丹药买家资金应在该范围内波动。
4. **广告影响**：对比不放招牌、放材料招牌时的概率预览；有广告时到访卖家只出售材料。观察多日比例变化，不用单日人数证明概率错误。
5. **快照和交易**：开门后移走展示物品、增加新类别或招牌，不应改变当天已生成五位的方向、类别、初始资金。任意丹药副本可售；错误类别混入柜台应锁定整笔交易；成交后资金减少，可继续卖给同一位或随时下一位。

原预算20/40/60、指定报价18的单件/连续/多件结算仍有隔离测试夹具（零售加价0）覆盖；它们不代表现在的默认客流或默认售价。

以上步骤用于开发者亲自确认可读性与手感；自动验证结果见 FIRST_PLAYABLE_VERIFICATION.md。
